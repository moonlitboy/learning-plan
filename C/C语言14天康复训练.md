> 目标：你已经学过一点 C 语言，但现在有遗忘。本计划不是“从零入门”，而是用 14 天、每天 3～4 小时，把 C 语言重新练到可以顺畅学习“数据结构（C 语言版）”的程度。
>
> 核心路线：
>
> **语法恢复 → 数组与函数 → 指针 → 字符串 → 结构体 → 动态内存 → 链表基础 → 综合训练**
>
> 最终目标不是“会背语法”，而是做到：
>
> 1. 能独立写中小型 C 程序；
> 2. 看见指针、结构体、`malloc` 不慌；
> 3. 能理解数据结构教材里的 `typedef struct`、指针传参、链式存储；
> 4. 能独立写出顺序表、单链表等数据结构的基础代码；
> 5. 具备继续学习栈、队列、树、图的语言基础。

# Day 06：数组与指针

## 今日目标

理解：

```text
数组名
数组首地址
指针运算
arr[i]
*(arr + i)
```

这是理解数据结构代码的重要桥梁。

---

## 1. 数组与地址

```c
int arr[5] = {10, 20, 30, 40, 50};
```

很多表达式中：

```c
arr
```

会表现为数组首元素地址。

也就是类似：

```c
&arr[0]
```

---

## 2. 指针访问数组

```c
int *p = arr;
```

然后：

```c
*p
```

等价于：

```c
arr[0]
```

而：

```c
*(p + 1)
```

等价于：

```c
arr[1]
```

---

## 3. 核心关系

必须记住并理解：

```c
arr[i]
```

等价于：

```c
*(arr + i)
```

不是死背。

要理解：

```text
指针 + 1
```

不是地址数字简单加 1，而是：

```text
移动一个对应类型元素的距离
```

---

## 1. malloc

```c
int *p = malloc(sizeof(int));
```

需要：

```c
#include <stdlib.h>
```

检查：

```c
if (p == NULL)
```


动态申请的内存不会像普通局部变量那样自动结束。

如果一直不释放：

---

## 1. 二级指针

```c
int **pp;
```

如果：

```c
int a = 10;
int *p = &a;
int **pp = &p;
```

那么：

```text
a   是 int
p   是 int *
pp  是 int **
```

---

## 2. 为什么数据结构里会出现 Node **

未来你可能看到：

```c
void init(Node **head);
```

原因是：

如果函数要修改：

```text
head 指针本身
```

就需要拿到：

```text
head 的地址
```

所以需要：

```text
Node **
```

# 五、C 语言学习时最容易踩的坑

## 1. `=` 和 `==`

赋值：

```c
a = 10;
```

比较：

```c
a == 10
```

---

## 2. 数组越界

```c
int arr[5];
```

合法下标：

```text
0～4
```

---

## 3. 指针没有初始化

危险：

```c
int *p;
*p = 10;
```

此时：

```text
p 指向未知位置
```

---

## 4. NULL 解引用

错误：

```c
int *p = NULL;
printf("%d", *p);
```

---

## 5. malloc 后忘记检查

推荐：

```c
Node *node = malloc(sizeof(Node));

if (node == NULL)
{
    return NULL;
}
```

---

## 6. malloc 后忘记 free

链表尤其容易出现。

---

## 7. free 后继续访问

```c
free(p);
```

之后不要：

```c
*p
```

---

## 8. 链表删除时丢失 next

例如准备删除当前节点前，一定注意：

```c
Node *next = current->next;
```

否则可能失去后续链表。

# 八、推荐编译方式

前几天：

```bash
clang main.c -o main
```

逐渐切换到：

```bash
clang -Wall -Wextra -Wpedantic main.c -o main
```

如果有多个文件：

```bash
clang main.c list.c -o main
```

后续学习数据结构时，你会慢慢开始使用：

```text
.h
.c
main.c
```

进行模块拆分。

例如：

```text
list.h
list.c
main.c
```

这可以放到正式数据结构阶段继续学习。

# 九、14 天以后，你应该达到什么程度

如果这 14 天认真完成，你应该可以自然理解下面这种代码：

```c
typedef struct Node
{
    int data;

    struct Node *next;
} Node;

Node *create_node(int value)
{
    Node *node = malloc(sizeof(Node));

    if (node == NULL)
    {
        return NULL;
    }

    node->data = value;
    node->next = NULL;

    return node;
}
```

你不应该只知道“这是链表代码”，而应该逐行知道：

```text
typedef 在干什么
struct 在干什么
Node * 是什么
malloc 为什么需要
sizeof 为什么这么写
node->data 是什么
node->next 为什么设为 NULL
return node 返回的是什么
```

如果能做到这一点：

**你的 C 语言康复就已经基本完成，可以正式进入数据结构。**
